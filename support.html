常見問題 / FAQ

成本試算會等於實際帳單嗎？

不會。試算採各模型卡標示核對日期的直接 API 公開牌價，並依您輸入的期間、呼叫數與 Token 用量假設計算。工具費、快取寫入、長上下文倍率、折扣、免費額度、稅金與市場通路加價可能不在估算內，實際金額請以供應商帳單為準。

Token 長度是精確結果嗎？文字會上傳嗎？

Token 工具是模型中立的離線粗略估算，不是特定 tokenizer 的精確計數；輸入文字只在裝置上處理，不會上傳。

決策專案存在哪裡？

專案、模型選擇、用量假設、採用決策與備註皆保存在您的裝置上，不需登入。

需要訂閱嗎？

本版功能免費，不需要帳號、訂閱或 App 內購買。

AI 動態會每日更新嗎？離線能閱讀嗎？

AI 動態讀取公開摘要，更新時間以畫面顯示的資料日期為準，不保證每日有新內容。成功載入後可離線閱讀最近的快取；首次安裝尚無快取時需先連線。過期提醒表示內容較舊，重新整理不一定會取得新資料。

新聞內容從哪裡來？

我們優先整理各 AI 實驗室的官方公告、研究文章與可追溯來源，並在每則摘要附上原始連結。摘要不代表相關公司的官方立場。

Is a subscription required? Can I read updates offline?

All features are free, with no account or subscription. AI Updates downloads public summaries and caches the last successful response. A first launch without a cache needs an internet connection.
